# Screenshots Directory

此目录用于存放项目截图。

## 需要添加的截图

请将主界面截图保存为 `screenshot.png` 并放在此目录：

**推荐截图区域：**
- 主界面完整视图（包含左侧词库、中间构建区、右侧预览）
- 分辨率建议：1920x1080 或 1280x720
- 格式：PNG

**添加步骤：**
1. 打开应用 (http://localhost:5173)
2. 截取主界面
3. 将截图保存为 `docs/screenshot.png`
4. 提交更改

## Screenshots Directory

## Required Screenshot

Please save a screenshot of the main interface as `screenshot.png` in this directory:

**Recommended:**
- Full main interface view (showing left library, center builder, right preview)
- Resolution: 1920x1080 or 1280x720
- Format: PNG

**Steps:**
1. Open the app (http://localhost:5173)
2. Capture the main interface
3. Save as `docs/screenshot.png`
4. Commit the changes
